# Fit-based workspace and explicit navigation

The shell reserves 228px for labeled navigation or 64px for the explicit rail. Work and conversation split only with at least 936px available; the conversation is clamped to the current range without rewriting its stored preference. Explicit expansion keeps a single work region across resize, with Work/Conversation selectors. Below 760px a modal native dialog contains the same labeled navigation, preserving actual actions and keyboard behavior. An explicit Expand navigation can temporarily show labels and use a single region when split cannot fit; viewport changes recalculate the automatic fit.

Activity groups real task/schedule views and the existing return-session summary. Needs you uses the same actionable unresolved collection as its badge. Apps remains the existing /library catalog with literal search and a normal-conversation discovery route.
